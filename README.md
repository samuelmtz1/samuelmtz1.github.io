# Samuel Martinez Jimenez: Portfolio

Source for my portfolio site. I'm an AI-native builder based in Mexico City, and I build web apps and tools by directing AI coding tools.

**Status:** in development. The site isn't published yet.

## Stack
- [Astro](https://astro.build) and TypeScript, built as a static site
- GitHub Pages and GitHub Actions for hosting and deployment, at no cost

## Add a project
Each project is one data file in `src/content/projects/`. In Claude Code, run:

```
/add-project <repo-or-project-name>
```

It drafts the entry for review, and nothing is published until I approve it.

## Run locally
Requires Node 22.23.4 or newer.

```
npm install
npm run dev      # local development server
npm run build    # checks for private data, then builds to dist/
```
